# Script-Controlled-ACL-Restrict-Record-Access-Based-on-Field-Value
Overview
Script-Controlled ACL is used to restrict record access based on a field value.

For example, if a record has Priority = Critical, only authorized users can access it. The ACL script checks the field value and user role, then allows or denies access dynamically
